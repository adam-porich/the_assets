This project is stored in GitHub. The `gh` tool is available.

`_notes/` may be used for scratch notes and research

`_plans/` may be used for plans. Do not create plans for simple work. If multiple plans are necessary, number them, for example `_plans/01-name.md`. Plans should use simple checklists, and completed items should be checked off.

When plans are complete they should be moved to `_notes/archived`. Don't leave completed plans in the _plans folder.

If you make file changes, commit and push them before returning to the user, unless the user explicitly asks otherwise. Alternatively, stash the changes with a clear message.

Always leave the repo in a good state.
